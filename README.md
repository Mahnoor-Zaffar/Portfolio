## File structure

- `index.html` - static entry point and metadata.
- `assets/css/main.css` - generated site stylesheet.
- `assets/css/custom-overrides.css` - preserved custom responsive and runtime override styles originally edited inline in `index.html`.
- `assets/js/app.js` - generated application bundle.
- `assets/js/runtime-optimizations.js` - preserved runtime image, text, and mobile flow helpers originally edited inline in `index.html`.
- `assets/images/` - local image assets used by the page.
- `assets/vendor/` - third-party or exported vendor scripts kept for reference.
- `docs/CNAME` - custom domain configuration.
